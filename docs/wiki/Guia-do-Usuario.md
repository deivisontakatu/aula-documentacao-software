# Guia do usuário

Este guia descreve os fluxos esperados do TaskFlow. Os passos devem ser confirmados na aplicação depois que cada funcionalidade estiver implementada.

## Criar uma tarefa

1. Abra a tela de tarefas.
2. Selecione a opção de criar tarefa.
3. Informe um título.
4. Opcionalmente, preencha a descrição.
5. Salve a tarefa.
6. Confirme que ela aparece na listagem.

**Resultado esperado:** a tarefa é exibida e o título não pode estar vazio.

## Editar uma tarefa

1. Localize a tarefa na lista.
2. Acione a opção de edição.
3. Atualize os campos desejados.
4. Salve e confira os dados atualizados.

## Alterar status

1. Localize a tarefa.
2. Selecione o novo status.
3. Confirme que a interface apresenta o estado atualizado.

Estados propostos: A fazer, Em andamento e Concluída.

## Excluir uma tarefa

1. Localize a tarefa.
2. Acione a opção de exclusão.
3. Leia a confirmação.
4. Confirme apenas se deseja realmente excluir.
5. Verifique se a tarefa deixou de aparecer na lista.

## Filtrar tarefas

1. Abra o controle de filtro.
2. Escolha o status desejado.
3. Confira se a lista contém somente os itens correspondentes.
4. Limpe o filtro para voltar à lista completa.

## Mensagens de erro

Leia a mensagem apresentada e confira os campos obrigatórios. Se o problema persistir, registre os passos para reproduzi-lo em uma issue, sem incluir senhas, tokens ou dados pessoais.
