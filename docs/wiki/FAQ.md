# FAQ e solução de problemas

## A aplicação já está implementada?

A existência das issues e desta documentação não comprova que as funcionalidades estejam implementadas. Consulte o código, os Pull Requests e os testes.

## Como instalar o projeto?

Siga o README da raiz do repositório. Esta wiki não inventa comandos ou versões de ferramentas; as instruções devem refletir a stack real.

## Por que uma tarefa não aparece no board?

Confirme se a issue foi adicionada ao GitHub Projects. Criar uma issue no repositório não garante que ela esteja incluída no projeto.

## O que significa uma issue estar em Testing?

Significa que a tarefa está aguardando validação dos critérios de aceite. Ela não deve ir para Done até que a validação esteja concluída.

## Como relatar um bug?

Abra uma issue contendo:
- Comportamento observado.
- Comportamento esperado.
- Passos para reproduzir.
- Ambiente em que ocorreu.
- Captura de tela ou log, se útil e seguro.

Não inclua senhas, tokens, dados pessoais ou outros segredos.

## Como sugerir uma funcionalidade?

Descreva o problema que deseja resolver, quem se beneficia, a solução proposta e os critérios que permitiriam verificar o resultado.

## Como atualizar a documentação?

Edite a página relacionada, revise links e exemplos e envie a mudança em um Pull Request junto com a alteração funcional correspondente.
