# Visão geral

## Objetivo

O TaskFlow é uma aplicação web didática destinada ao gerenciamento de tarefas. Seu propósito é servir como exemplo para praticar planejamento, desenvolvimento, testes e documentação de software.

## Problema

Equipes e indivíduos precisam registrar atividades, acompanhar o andamento e localizar rapidamente o que ainda precisa ser feito.

## Usuários previstos

- Pessoas que precisam organizar tarefas pessoais.
- Pequenas equipes que desejam acompanhar atividades.
- Estudantes que estão aprendendo o ciclo de desenvolvimento de software.

## Funcionalidades previstas para o MVP

- Criar e listar tarefas.
- Editar e excluir tarefas.
- Alterar o status de uma tarefa.
- Filtrar tarefas por status.

Funcionalidades como autenticação, persistência em banco de dados, busca textual e paginação aparecem no backlog como evoluções propostas.

## Status do projeto

Este repositório contém issues que simulam etapas e melhorias do produto. Consulte as [issues](../../issues) para verificar o planejamento. A existência de uma issue não comprova que a funcionalidade já esteja implementada.

## Termos utilizados

- **Issue:** cartão de trabalho que descreve uma tarefa, melhoria ou problema.
- **MVP:** versão mínima que atende ao conjunto essencial de requisitos.
- **Sprint:** período de trabalho planejado pela equipe.
- **Critério de aceite:** condição verificável para aceitar uma entrega.
- **Definition of Done:** conjunto de condições para considerar uma tarefa concluída.
