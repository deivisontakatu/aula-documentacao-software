# Instalação e deploy

## Estado atual

A stack, os comandos de instalação e a plataforma de hospedagem devem ser preenchidos após a confirmação da implementação. Não execute comandos presumidos sem conferir o README e os arquivos do projeto.

## Preparação local

1. Instale as ferramentas exigidas pelo projeto.
2. Clone o repositório.
3. Confira a versão da linguagem e do gerenciador de pacotes.
4. Instale as dependências conforme o README.
5. Configure variáveis de ambiente necessárias usando valores locais e seguros.
6. Execute a aplicação e os testes pelos comandos documentados.

## Variáveis de ambiente

- Documente apenas os nomes e a finalidade das variáveis.
- Use valores fictícios nos exemplos.
- Nunca versionar arquivos com credenciais reais.
- Se houver um arquivo de exemplo, mantenha-o sem segredos.

## Deploy

Antes de publicar:

- Confirme que build e testes passaram.
- Configure segredos na plataforma de hospedagem.
- Execute o deploy seguindo o processo aprovado.
- Teste o fluxo principal no ambiente publicado.
- Registre a URL somente depois de verificar que ela funciona.
- Consulte logs em caso de falha.

## Rollback

Se houver uma versão anterior estável e o processo permitir, documente como retornar a ela. Não afirme que rollback automático existe sem implementação.
