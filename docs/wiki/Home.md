# Wiki — TaskFlow

Bem-vindo à documentação do **TaskFlow**, uma aplicação web didática de gerenciamento de tarefas. Esta documentação acompanha a simulação de desenvolvimento de software do repositório.

> **Importante:** o TaskFlow é um projeto didático. As funcionalidades descritas como planejadas não devem ser consideradas implementadas até que exista código e evidência de validação.

## Sobre esta documentação

As páginas são mantidas em Markdown dentro de `docs/wiki/` para facilitar revisão por Pull Request e versionamento junto ao código. Elas podem ser copiadas para o recurso GitHub Wiki, caso o projeto passe a utilizá-lo.

## Como contribuir

1. Escolha a página relacionada à mudança.
2. Edite a documentação junto com a alteração de código correspondente.
3. Confira links, exemplos e nomes de arquivos.
4. Abra um Pull Request descrevendo o que mudou.
5. Não documente como concluído algo que ainda está apenas planejado.
