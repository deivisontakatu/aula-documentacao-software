# Como contribuir

Este repositório apoia o aprendizado de documentação de software. Contribuições podem incluir correções, exemplos, melhorias de clareza e novos materiais didáticos.

## Antes de começar

1. Leia o [README](README.md) para entender o objetivo e a estrutura do repositório.
2. Confira se a alteração proposta já existe ou está sendo discutida em uma Issue.
3. Para mudanças relevantes, abra uma Issue descrevendo o problema ou a proposta antes de implementar.

## Fluxo recomendado

1. Atualize sua cópia da branch `main`.
2. Crie uma branch com nome descritivo, por exemplo:
   - `docs/corrige-requisitos`
   - `docs/exemplo-api`
   - `fix/corrige-link`
3. Faça uma alteração pequena e focada.
4. Revise o conteúdo e confira os links e a formatação Markdown.
5. Registre commits com mensagens claras, como `docs: esclarece critérios de aceite`.
6. Envie a branch ao GitHub e abra um Pull Request para `main`.
7. Descreva o objetivo, os arquivos alterados e como a mudança foi verificada.
8. Responda aos comentários de revisão e atualize a branch quando necessário.

## Padrões para documentação

- Escreva em português claro e use títulos hierárquicos.
- Prefira exemplos pequenos, realistas e fáceis de acompanhar.
- Identifique exemplos fictícios e endpoints ilustrativos.
- Não afirme que uma funcionalidade, API ou teste existe sem evidência.
- Não inclua senhas, tokens, chaves de API ou dados pessoais.
- Mantenha o README e os documentos relacionados consistentes.
- Use tabelas quando ajudarem na comparação; evite tabelas excessivamente longas.
- Confira se os caminhos dos arquivos e links estão corretos.

## Checklist para Pull Requests

- [ ] A alteração tem objetivo claro e escopo limitado.
- [ ] O texto foi revisado quanto à clareza e ortografia.
- [ ] Os links e caminhos foram conferidos.
- [ ] Exemplos fictícios estão identificados como tais.
- [ ] Nenhum segredo ou dado sensível foi incluído.
- [ ] Documentos relacionados foram atualizados.
- [ ] A descrição do PR explica o que mudou e como revisar.

## Revisão

Comentários devem ser respeitosos, específicos e acionáveis. Ao sugerir uma mudança, explique o problema e, quando possível, apresente uma alternativa.

Obrigado por ajudar a melhorar o material!
